PULSA KITA - PHP NATIVE + BOOTSTRAP 5

Versi ini berdiri sendiri dan tidak menggunakan Laravel, Blade, Artisan, Composer, atau Vite.

CARA MENJALANKAN:
1. Ekstrak folder pulsa-kita-native ke C:\laragon\www\pulsa-kita-native
2. Buka Laragon dan klik Start All.
3. Buka browser: http://localhost/pulsa-kita-native/

HALAMAN:
- index.php: beranda
- produk.php: pilihan Pulsa dan Paket Data
- detail-produk.php: detail produk
- pembayaran.php: simulasi QRIS
- login.php dan register.php: tampilan autentikasi (belum menyimpan akun)

CATATAN PENTING:
- Harga dan produk masih data contoh.
- Pembayaran masih simulasi.
- Login/registrasi dan penyimpanan pesanan MySQL belum diaktifkan.
- config/database.php sudah disiapkan untuk koneksi MySQL tahap berikutnya.
- CSS lama dan logo dipertahankan; Bootstrap 5 dipanggil dari CDN.
