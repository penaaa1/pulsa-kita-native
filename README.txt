# PULSA KITA — PHP NATIVE + BOOTSTRAP 5

Website penjualan pulsa dan paket data menggunakan PHP Native dan Bootstrap 5. Proyek ini masih dalam tahap pengembangan untuk memenuhi tugas Proyek 1.

## CARA MENJALANKAN

1. Ekstrak folder `pulsa-kita-native` ke `C:\xampp\htdocs\pulsa-kita-native`.
2. Buka XAMPP Control Panel.
3. Jalankan Apache dan MySQL dengan klik Start.
4. Buka browser dan akses: http://localhost/pulsa-kita-native/

## HALAMAN

- `index.php` — Beranda
- `produk.php` — Pilihan Pulsa dan Paket Data
- `detail-produk.php` — Detail produk
- `pembayaran.php` — Simulasi pembayaran QRIS
- `login.php` dan `register.php` — Tampilan autentikasi

## CATATAN

- Harga dan produk masih berupa data contoh.
- Pembayaran masih berupa simulasi.
- Login dan registrasi belum terhubung dengan penyimpanan akun.
- Database masih dalam tahap pengembangan.
- Bootstrap 5 digunakan untuk mendukung tampilan website.
